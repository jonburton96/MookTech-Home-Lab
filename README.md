# MookTech Home Lab

A virtualized enterprise-style IT and cybersecurity home lab built with VMware to develop hands-on experience with networking, Windows Server, Active Directory, DNS, user management, file sharing, and access control.

MookTech is a fictional organization used to simulate a small enterprise IT environment.

## Lab Environment

- VMware virtualization
- Windows Server
- Windows 11 Enterprise
- Active Directory Domain Services
- DNS
- Domain: `home.lab`
- Isolated `/29` IPv4 network

### Network

| Device | IP Address | Role |
|---|---|---|
| Windows Server | `192.168.10.3` | Domain Controller / DNS |
| Windows 11 Client 1 | `192.168.10.1` | Domain Client |
| Windows 11 Client 2 | `192.168.10.2` | Domain Client |
